Mathematical
Logic

Mathematical Logic is the rulebook for clear and correct thinking. In mathematics, getting the correct answer is important, but proving that every step of reasoning is correct is equally important.

Statements

A statement is a declarative sentence that is either:

  • True (T)
  • False (F)

but not both at the same time.

2 + 3 = 99 → False (F)

Truth Value

Statement Type Truth Value
True Statement T (True)
False Statement F (False)

Logical Connectives

Logical connectives connect two or more simple statements.

Connective Symbol Name Tip to learn
and ∧ Conjunction True only if both statements are true
or ∨ Disjunction False only if both statements are false
not ∼ Negation Reverses truth value
if...then → Conditional False only when p is true and q is false(if p → q is a statements)
if and only if ↔ Bi-conditional True when both statements have same truth values

Tautology & Contradiction

  • Tautology: Final column of truth table contains only True values.
  • Contradiction: Final column of truth table contains only False values.
  • Contingency: Contains both True and False values .

Quantifiers

∀x ∈ N, x + 0 = x

Universal Quantifier → “For all”

∃x ∈ N such that x² = 4

Existential Quantifier → “There exists”

Duality

  • ∧ and ∨ get replace

Rules of Negation

∼(p∧q) ≡ ∼p∨∼q
∼(p∨q) ≡ ∼p∧∼q
∼(p→q) ≡ p∧∼q
∼(p↔q) ≡ (p∧∼q) ∨ (q∧∼p)

Laws of Mathematical Logic

1. Commutative Laws

p ∨ q ≡ q ∨ p
p ∧ q ≡ q ∧ p

2. Associative Laws

(p ∨ q) ∨ r ≡ p ∨ (q ∨ r)
(p ∧ q) ∧ r ≡ p ∧ (q ∧ r)

3. Distributive Laws

p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)

4. De Morgan's Laws

∼(p ∧ q) ≡ ∼p ∨ ∼q
∼(p ∨ q) ≡ ∼p ∧ ∼q

5. Idempotent Laws

p ∨ p ≡ p
p ∧ p ≡ p

6. Complementary Laws

p ∨ ∼p ≡ T
p ∧ ∼p ≡ F

7. Identity Laws

p ∨ F ≡ p
p ∧ T ≡ p

8. Absorption Laws

p ∨ (p ∧ q) ≡ p
p ∧ (p ∨ q) ≡ p

9. Involution Law

∼(∼p) ≡ p

10. Conditional Laws

p → q ≡ ∼p ∨ q
∼(p → q) ≡ p ∧ ∼q

11. Biconditional Laws

p ↔ q ≡ (p → q) ∧ (q → p)
p ↔ q ≡ (p ∧ q) ∨ (∼p ∧ ∼q)

Variations of Implication

Type Form
Converse q → p
Inverse ∼p → ∼q
Contrapositive ∼q → ∼p

Switching Diagrams

p ∧ q → Series Connection (AND)

Current flows only when both switches are closed.

p ∨ q → Parallel Connection (OR)

Current flows if at least one switch is closed.

How to Read Circuits

  • p and q represent switches
  • ∼p is written as S₁′
  • Parallel branches → ∨
  • Same wire → ∧
  • Use Battery, Lamp (L), and switches
  • 1 = ON / True
  • 0 = OFF / False
Result Type
Always ON Tautology
Always OFF Contradiction
Sometimes ON/OFF Contingency
